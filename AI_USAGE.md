# Использование AI

## Роль Codex

Исходный MVP этапа 1 создан с помощью Codex непосредственно в папке VS Code. Исходное задание: разработать учебное приложение «Что приготовить?» на FastAPI, SQLAlchemy и SQLite с русским интерфейсом без frontend-фреймворков, подбором по продуктам, ТЗ, документацией, начальными тестами и файлами Docker.

Codex создал файлы приложения и документации, установил зависимости в локальное `.venv`, выполнил проверки и сохранил логические части отдельными коммитами в `mvp`. Имя автора `nekentoss` и пустой email заданы пользователем. Точное название модели и действия студента вне этой сессии не фиксируются, поскольку подтверждённых данных о них нет.

## Фактически выполненные проверки

Среда подготовки: macOS, Python 3.9.6, Git 2.50.1, GitHub CLI 2.97.0, Chrome 156.0.8078.47. Docker не найден.

- Установка зависимостей из `requirements-dev.txt` в `.venv`; `pip check` не обнаружил конфликтов.
- `python -m pytest`: **42 теста прошли**. Проверены полный, частичный и нулевой результат подбора, повтор выбранных ID, пустой выбор, сортировка до округления, порядок по названию и ID.
- API-тесты с отдельной временной SQLite проверили создание, получение, изменение и удаление рецептов, сохранение продуктов, ошибки данных и неизвестных ID, 404, дубли названий на кириллице, внешние ключи и повторное демозаполнение без изменения пользовательских данных.
- Приложение запущено через Uvicorn с отдельной временной базой. Реальные HTTP-запросы к `/`, `/docs`, `/openapi.json`, CSS и JavaScript вернули 200. Через HTTP дополнительно проверены добавление продукта, CRUD рецепта, подбор, ошибки 422 и ответ 404 после удаления.
- Через `python -m app.seed` создана локальная демонстрационная база: 15 продуктов и 6 рецептов. Повторный запуск добавил 0 продуктов и 0 рецептов. База не включена в Git.
- В настоящем headless Chrome через DevTools проверены загрузка интерфейса, добавление продуктов, ошибки пустого ввода и дублей, создание рецепта, просмотр инструкции, изменение названия, инструкции и состава, отмена и подтверждение удаления, подбор и сообщение об отсутствии совпадений. Пользовательские строки с HTML-тегами отображались как текст и не выполнялись. Необработанных ошибок JavaScript не обнаружено.
- Получены проверочные скриншоты настольного и мобильного вида во временной папке; на ширине 390 px горизонтальной прокрутки нет. Для браузерной проверки использовались временная БД и отдельный профиль Chrome, пользовательская база не изменялась.
- `node --check app/static/app.js` завершился успешно.
- `compose.yaml` прочитан стандартным YAML-парсером; проверены опубликованный локальный порт и наличие именованного тома.

Временные проверочные сценарии и скриншоты не входят в учебный репозиторий; воспроизводимые начальные тесты находятся в `tests/`.

## Что не проверено и не выполнялось

Сборка Docker-образа, запуск Compose и сохранность SQLite после пересоздания контейнера не проверены: Docker отсутствует. Для этих проверок нужно установить и запустить Docker Desktop, затем выполнить команды из README.

Удалённый репозиторий не создавался, push и PR не выполнялись по требованию пользователя. Code review, отчёт по покрытию, измерение метрик, CI, pre-commit и рефакторинг следующих этапов не выполнялись. Файлы REVIEW.md, ANALYSIS.md и REFACTORING.md не создавались.
